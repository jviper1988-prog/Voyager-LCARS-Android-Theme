VOYAGER LCARS — HOW TO GET A REAL APK

This is a functional Android launcher source project, NOT an APK.

OPTION A: Android Studio on Windows/Mac/Linux
1. Extract the project ZIP.
2. Open Voyager_LCARS_Launcher in Android Studio.
3. Install requested SDK components and sync Gradle.
4. Select Build > Build APK(s).
5. Install app/build/outputs/apk/debug/app-debug.apk on your Samsung.

OPTION B: GitHub Actions cloud build
1. Extract the ZIP and put the contents of the Voyager_LCARS_Launcher folder
   in the root of a GitHub repository (including .github/workflows).
2. Open the repository's Actions tab and run "Build Voyager LCARS APK".
3. Download the build artifact; unzip to obtain app-debug.apk.
4. Install on your S24 Ultra; make Voyager LCARS the Home app only after testing.

To revert on Samsung: Settings > Apps > Choose default apps > Home app > One UI Home.
The launcher does not replace Samsung lock screen or Quick Settings.
No physical-device installation was tested in this environment.
