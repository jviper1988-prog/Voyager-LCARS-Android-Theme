# v1.2.3 — LCARS dial pad

Adds a native Android LCARS number pad from COMMUNICATIONS. Amber digit keys, violet controls, blue number display, delete/clear, international + by holding 0, and an explicit Continue to Phone handoff. The user must press Call in their existing phone app. No call is placed by the launcher. No new permissions or contacts access.

Incoming/active-call screens remain in Samsung Phone (or the selected phone app). This is not a full replacement phone app. Native device behavior needs testing. User confirmed the separately configured Samsung Keyboard LCARS theme was applied and works.

Before updating: export any Captain's Log entries. Debug builds may use different signing keys; if Android rejects the update, switch Home to One UI Home, uninstall the old test build, and install the new one. Uninstalling erases launcher logs and favorites, but not the separately applied Samsung keyboard theme.
